# Dashboard Specification

## Pages
1. Executive Dashboard
2. Operational Dashboard
3. Management Dashboard
4. Fraud & Risk Analysis
5. Branch and Channel Intelligence

## Required Features
- Dark banking theme
- Bookmarks + navigation buttons
- Drillthrough to customer and branch pages
- Tooltip pages for KPI cards
- Dynamic titles with field parameters
- Slicers (Date, Branch, Channel, Segment)
- Cross-filtering enabled

## Required Visuals Mapped
- KPI cards: transactions, revenue, fraud %, risk %
- Map: geo transaction distribution
- Tree map: merchant category split
- Waterfall: balance movement
- Ribbon chart: channel trend
- Scatter: risk score vs amount
- Decomposition tree: fraud drivers
- Key influencers: churn and fraud indicators
- Forecast + anomaly detection: daily transaction series
